# SkyAirBan

새로 생성된 청크에서 하늘과 연결된 초기 공기 위치에 플레이어가 블록을 설치하지 못하게 하는 Paper 플러그인입니다.

## 설치와 빌드

- 이 프로젝트는 Paper 26.3 API와 Java 25를 기준으로 빌드합니다. 서버에는 Paper 26.3과 Java 25가 필요합니다.
- Java 25와 Gradle을 준비하고 프로젝트 폴더에서 `gradle build`를 실행합니다. 테스트도 함께 실행됩니다.
- 서버를 종료한 뒤 `build/libs/SkyAirBan-1.0.0.jar`를 서버의 `plugins` 폴더에 넣고 서버를 시작합니다.
- 명령어와 설정 파일은 없습니다.

## 동작

- 새 청크의 생성 및 장식이 끝나면 월드 최상단의 공기에서 시작해 같은 청크 안에서만 상하좌우앞뒤로 연결된 `AIR`, `CAVE_AIR`, `VOID_AIR`를 기록합니다. 물, 나뭇잎 등 공기가 아닌 블록은 통과하지 않습니다.
- 기록된 좌표에 플레이어가 블록을 직접 설치하려 하면 설치가 취소되고 낮은 음의 소리가 납니다. 여러 블록을 한 번에 설치하는 이벤트는 모든 대상 위치를 검사합니다.
- 처음에 막혀 있던 동굴이나 처음에 고체였던 블록을 캐낸 자리는 설치할 수 있습니다. 블록을 캐거나 설치해도 기록은 바뀌지 않습니다.
- 기록은 청크의 영구 데이터에 저장되며 청크 저장 및 서버 재시작 후에도 유지됩니다. 피스톤, 낙하 블록, 유체 등 간접적인 변경은 제한하지 않습니다.

## 제한 및 주의

- 기존 청크나 플러그인이 꺼져 있을 때 생성된 청크는 초기 상태를 알 수 없으므로 소급 기록하지 않으며 설치를 제한하지 않습니다. 플러그인이 활성화된 뒤 새로 생성되는 청크에만 적용됩니다. 이미 생성된 스폰 청크도 해당됩니다.
- 다른 청크를 불러오지 않기 위해 연결 탐색은 대상 청크 경계에서 끝납니다. 하늘로 나가는 유일한 경로가 이웃 청크를 지나가는 공기는 기록되지 않을 수 있습니다.
- 다른 플러그인이 청크 생성 이벤트 이후 지형을 변경해도 최초 기록은 갱신하지 않습니다.
- 청크를 정상 저장하기 전 서버가 비정상 종료되면 해당 청크와 기록이 마지막 저장 상태로 돌아갈 수 있습니다. 청크의 기록이 손상되거나 월드 높이가 변경되면 오류를 로그에 남기고 해당 청크의 직접 설치를 차단합니다. 복구 전 월드 백업을 권장합니다.
